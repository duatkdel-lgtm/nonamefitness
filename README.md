## 콘텐츠 및 SEO 관리

홈페이지의 사업자 정보, 운영시간, 프로그램, 상담 링크를 변경할 때는 다음 항목을 함께 확인합니다.

1. `index.html`의 본문과 JSON-LD 구조화 데이터
2. 페이지별 `title`, `description`, Open Graph 이미지와 URL
3. `sitemap.xml`에 새 페이지가 포함되었는지 여부
4. 네이버 예약, 블로그, 인스타그램 링크의 최신 상태
5. 대표 이미지의 대체 텍스트와 지역 키워드의 자연스러운 반영

지역 키워드는 한 페이지에 반복해서 넣기보다, 각 페이지의 실제 내용과 목적에 맞춰 사용합니다. 예를 들어 PT 페이지는 `두정동 PT`, 시설 소개는 `두정동 헬스장`, 스피닝 페이지는 `천안 스피닝` 중심으로 작성합니다.

## 운영 원칙

- 이용권 가격, 이벤트, 수업 시간은 확인된 최신 정보만 게시합니다.
- 비포·애프터, 회원 후기, 운동 효과 관련 콘텐츠는 실제 사례와 동의 범위 안에서만 사용합니다.
- 문의·예약 링크와 주소·전화번호는 홈페이지, 네이버 플레이스, 블로그에서 동일하게 유지합니다.
